# Form Reader and Checker

Based on a task I have seen administrative roles completing at my workplace, I want to attempt to automate 
the process using python. The idea of this project is to see what libraries I need, the complexity of the
implementation, and how well the reader and checker is able to complete the tasks. It is possible that this
could also include a signature matching engine, which checks the signatures on documents, to see whether it 
matches the signature you would hold on a file.
